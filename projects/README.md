# IRIS RC1 projects

These projects progress from multi-file application logic to learning and native
code evolution. Their default entry points are deterministic and assertion-backed.
Run commands from the repository root. External services and physical hardware
are opt-in integrations documented in the relevant project.

| Project | Entry | Scope |
| --- | --- | --- |
| [Interactive learning scheduler](learning_scheduler/README.md) | `projects/learning_scheduler/main.iris` | Terminal controls, learned scheduling, policy comparisons, bounded CPU jobs, and recovery |
| [Learning robot: train and adapt](learning_robot/WORKFLOW.md) | `projects/learning_robot/trajectories.iris` | Trajectory learning, drift detection, held-out comparisons, checkpointing, and recovery |
| [Beginner: checked ledger](ledger/README.md) | `projects/ledger/main.iris` | No service, credentials, or files |
| [Intermediate: structured job pipeline](job_pipeline/README.md) | `projects/job_pipeline/main.iris` | No service or credentials |
| [Advanced: software-only learning service](learning_service/README.md) | `projects/learning_service/main.iris` | No hardware, datasets, or external model runtime |
| [Advanced: LLM application gateway](model_gateway/README.md) | `projects/model_gateway/main.iris` | The default run is offline |
| [Advanced: simulated actuator controller](robotic_actuator_control/README.md) | `projects/robotic_actuator_control/src/main.iris` | Default execution is simulation only: no serial connection, GPIO writes, or DDS transport |

| [In-memory JIT superoptimizer](jit_superoptimizer/README.md) | `projects/jit_superoptimizer/main.iris` | Micro-op IR cost modeling, peephole strength reduction, shift coalescing, identity folding, and formal mathematical equivalence verification across 4,000+ fuzzing vectors |
| [Autonomous drone hunter](autonomous_drone_hunter/README.md) | `projects/autonomous_drone_hunter/main.iris` | 3D multi-spectral search, terrain occlusion raycasting, evasive target pursuit, laser standoff designation, and idiomatic telemetry debriefing |
| [Continuous background learning](continuous_background_learning/README.md) | `projects/continuous_background_learning/main.iris` | 50 Hz real-time control, concurrent asynchronous parameter identification via `spawn`, Normalized LMS adaptation under plant drift, in-flight model hot-swapping, and real-time ASCII oscilloscope |
| [Starter template (hello_iris)](hello_iris/README.md) | `projects/hello_iris/main.iris` | Minimal starter project scaffolded via `iris pkg init` with `iris.toml` manifest, idiomatic records, and standard library demonstration |
| [Turtlesim autopilot (ROS 2)](turtlesim_autopilot/README.md) | `projects/turtlesim_autopilot/main.iris` | Live ROS 2 node: turtlesim services, the rotate_absolute action, pose topics, live-tunable parameters and tf2; `simulate.iris` checks the controller offline |
| [Lifecycle sensor fusion (ROS 2)](lifecycle_sensor_fusion/README.md) | `projects/lifecycle_sensor_fusion/main.iris` | rclcpp_lifecycle node fusing two range sensors with a gated Kalman filter; driven by itself or by `ros2 lifecycle`; `simulate.iris` checks the filter offline |
| [Evolving cart controller](evolving_cart_controller/README.md) | `iris evolve-live` on `projects/evolving_cart_controller/` | A cart keeps running while its controller is replaced under the seven gates, rejected by the allocation-free proof, and rolled back on a field violation; `reference.iris` derives the LQR law the canary uses |
| [Evolving turtle](evolving_turtle/README.md) | `projects/evolving_turtle/run.ps1` or `run.sh` (ROS 2 + turtlesim) | A robot in a ROS 2 simulator keeps driving while its controller is replaced: an allocating candidate refused, an unclamped one promoted then rolled back at the speed limit, the saturated one kept, the audit chain verified |
| [Self-upgrading inventory service](self_upgrading_service/README.md) | `iris evolve-serve` on `projects/self_upgrading_service/`, driven by `client.iris` | An HTTP service promoted to a new version while it serves, with its stock and counters carried over; unsafe and retyped versions refused at their gates; rollback carries the state back |
| [Arduino Uno controls](uno_controls/README.md) | `projects/uno_controls/simulate.iris`; board entries `uno_*.iris` | Press-to-toggle, a debounced four-mode lamp and a fixed-point PID with anti-windup, as allocation-free step functions over program state; checked on the host on both backends and proven for the Uno; not yet flashed |
| [Async quote gateway](async_gateway/README.md) | `projects/async_gateway/main.iris`; `selftest.iris` runs offline | HTTP service with one async thread: per-request fan-out to three suppliers, 150 ms deadlines, cancellation of late calls, a first-answer race; 64 concurrent clients answered with all 64 in flight natively. Suppliers are simulated with timers |
| [Command-line tools](cli_tools/README.md) | `csvq`, `logstat`, `pcapinspect`, `tlsfp` in `projects/cli_tools/`; `iris run tool.iris -- args` | CSV (RFC 4180) and JSON Lines filtering, grouping and conversion; access-log analysis; pcap inspection (either byte order); JA3/JA4 TLS fingerprints. Checked on both backends against an independent Python implementation; no TCP stream reassembly, no pcapng |
| [Warehouse agent (LLM tools)](llm_agent/README.md) | `projects/llm_agent/selftest.iris` offline; `main.iris` against an OpenAI-compatible endpoint | IRIS functions as typed tools for a chat model: arguments decoded and range-checked into records before anything runs, results encoded from records, refusals as typed errors. Checked on both backends with a scripted stand-in and over HTTP against a mock server; one live run with Mistral 7B in Ollama |
| [Gridworld agent (active inference)](gridworld_inference/README.md) | `projects/gridworld_inference/run.iris` | Learns an unknown grid online (Dirichlet model with forgetting, expected free energy with a novelty term), reaches the best possible policy, relearns when a wall appears; compared with a random walk and the optimum. Fully observed, tabular, one seeded run |
| [IRIS mission intelligence](mission_intelligence/README.md) | `projects/mission_intelligence/main.iris` | Research prototype (Eclipse Softworks, 2029 target): Keplerian orbital telemetry, autonomous dipole equation recovery ($R^2 > 0.99$), multi-sigma anomaly detection, epistemic experiment planning (+181% yield advantage), and independent 4-gate hard safety governor |

The [example catalog](../examples/catalog.json) indexes every IRIS source as an
entry, reusable module, or explicit integration. It is checked by
